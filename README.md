# Homebrew tap for Taped

[Taped](https://tapedapp.com) is a menubar video archiver for macOS.

```sh
brew install --cask drahosistvan/tap/taped
```

Or tap once, then use the short name:

```sh
brew tap drahosistvan/tap
brew install --cask taped
```

The app updates itself with Sparkle. The cask in this repository is bumped automatically
by the release workflow on every new version.
